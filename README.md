# 紫记 · 日常账本

浅紫色的本地记账程序，支持 Windows 桌面版和浏览器版。

## Windows 软件

双击项目文件夹中的 **紫记.exe**，打开独立软件窗口。程序不需要安装 Python 或 Node.js。本机使用 Microsoft Edge WebView2 运行界面；如其他电脑缺少运行时，可从微软官网下载并安装：https://developer.microsoft.com/microsoft-edge/webview2/

桌面版的数据文件均在 **紫记.exe 所在文件夹**，当前为项目文件夹：

- `账本.json`：完整账本，首次启动创建，每次保存即时更新。
- `账本.上一版.json`：自动保留上一次保存的账本，必要时可通过「导入账本」恢复。
- `导出/`：点击导出备份或导出每日明细后生成的文件。

请把软件放在有写入权限的文件夹。移动软件时，请同时移动 `账本.json` 与备份文件。关闭软件后再手动修改账本；同一文件夹只允许一个软件实例运行。桌面版与浏览器版数据分别保存，如需要把浏览器账本带入桌面版，先在浏览器版导出备份，再在桌面版导入。

桌面源码入口为 `desktop.py`，打包脚本为 `build_desktop.py`。重新打包：

```powershell
python -m venv .desktop-venv
.\.desktop-venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.desktop-venv\Scripts\python.exe build_desktop.py
```

## 开始使用

双击 `index.html`，用 Chrome 或 Edge 浏览器打开。初始包含微信、支付宝、银行卡三个零余额账户。先在「账户管理」设置余额，再点击「记一笔」记录日常开销。

- 自由添加、编辑账户名称、类型和当前余额。
- 支出自动扣减余额，收入自动增加余额，总余额同步更新。
- 编辑账单会先撤销原记录的余额变动，再应用新记录；删除记录会恢复余额。
- 有关联账单的账户不能直接删除，避免历史账单丢失。无关联账单的账户可以删除。
- 按日期查看每日收支，支持账户筛选、备注搜索、每日 CSV 明细导出。
- 「开销统计」显示每月收支、每日支出和分类占比，点击每日柱形可查看当天账单。
- 「导出备份」保存完整 JSON 账本，「导入账本」校验后替换当前数据。

浏览器版数据存储在当前浏览器的本地存储中；桌面版数据保存在软件所在文件夹。不连接微信、支付宝或银行，余额需要手动设置。浏览器版更换浏览器、清理浏览器数据、移动文件或使用隐私模式可能导致原账本不可用，请定期导出备份。编辑账户余额会直接校准余额，不生成收支记录。程序允许负余额并在支出后提示，以便补记历史支出。

## 验证

安装 Node.js 后运行：

```sh
node core.test.cjs
python desktop.test.py
```

文件结构：`index.html` 页面、`style.css` 样式、`app.js` 交互、`core.js` 金额与账本逻辑。
