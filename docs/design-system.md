# zz记视觉设计规范

当前界面采用用户选定的 A 方案：深紫导航栏、暖白主区、衬线金额与植物线稿。延续编辑式排版和克制的组件层次，保留 zz记 的个人财务软件定位。

## 现有问题与设计方向

旧样式多次叠加覆盖，9–11px 小字偏多，正文、金额、操作都倾向紫色。纹理、高光和多个渐变分散了关键信息。本次用单一 token 系统代替叠加主题，先确定待还款页的语言，再应用到总览、账户、统计和弹窗。

首页左侧集中展示总余额、每日和月度支出，右侧展示账户列表与待还款摘要。每日账单仍在下方，滚动即可查看。深紫色用于侧栏与主操作，金额使用深紫墨色；账户列表用细分割线与右对齐余额建立清晰层次。

## 色彩

| Token | 颜色 | 用途 |
| --- | --- | --- |
| `--bg` | `#FAF8F5` | 暖白主区背景 |
| `--surface` | `#FFFEFC` | 表单和业务卡片 |
| `--surface-secondary` | `#F0EBF3` | 待还款摘要、弱强调 |
| `--sidebar-bg` | `#302139` | 深紫导航栏 |
| `--purple` | `#927AA5` | 图标、焦点、品牌强调 |
| `--purple-dark` | `#50355E` | 主操作与重点信息 |
| `--ink` | `#2C1D38` | 标题与关键金额 |
| `--text` | `#5D5265` | 正文 |
| `--muted` | `#978A9F` | 次要元信息 |
| `--text-secondary` | `#776981` | 小字标签，保持可读性 |
| `--border` | `#E3DCE7` | 边框与分割线 |

逾期、已还清、今日到期使用独立的低饱和语义色，并同时显示文字，不只靠颜色表达状态。

## 排版

- 主标题：桌面 39px，窄窗口 34px，使用宋体风格衬线字形。
- 首页账户列表标题 20px，名称 15px，余额 26px。
- 首页总余额 48–82px，宽屏最高 86px；窄窗口 62px，极窄窗口 53px。其他重点金额保留 30–36px。
- 正文与主要操作：13px；标签、日期说明与辅助操作：11–12px。
- 中文字体按本机可用的 Noto Sans SC、思源黑体、微软雅黑等回退，无在线字体依赖。
- 标题按 Noto Serif SC、思源宋体、宋体回退；数字使用本机 Georgia 等衬线字体，余额右对齐。常规正文保留无衬线字体，无在线字体依赖。

## 组件

- 标题栏高 44px，使用细分割线，保留全部原生控制与拖动。
- 导航宽 220px，窄窗口收至 196px 或 184px；导航项高 48px。
- 卡片圆角 12px，边框 1px；按钮圆角 4px，输入框圆角 5px。
- 采用 4、8、12、16、20、24、32、40px 间距刻度。
- 待还款总额使用深灰紫锚点，次级统计通过分割线组织。明细卡突出金额、状态、日期和操作。
- 首页左右按约 40% / 60% 分栏；宽度不超过 1120px 时上下排列，隐藏装饰图片以优先保留数据。
- 账户列表的箭头可直接编辑对应账户；添加账户、管理账户和每日账单入口全部保留。
- 每日开销明细位于首页左侧余额及支出概览下方，保留日期切换、收支汇总、账户筛选、搜索、导出和编辑操作。总览页不再使用花束装饰。
- 左侧栏以连续深紫底色组织品牌、低饱和灰紫色月相与橄榄枝勾线图案、导航和底部短句；装饰不接收鼠标事件，矮窗口缩小插图以保留操作空间。
- 明细在宽窗口为三列，普通桌面为两列，窄窗口为一列。内容独立滚动。
- Hover 仅改变边框、背景或文字，过渡 180ms；尊重减少动态效果的系统设置。
- Focus 使用品牌色细描边和柔和焦点环；错误与保存状态有明确文字反馈。
- 模态对话框使用普通半透明遮罩，不使用毛玻璃或滤镜。

## 文件组织与验证

`ui/style.css` 引入基础 tokens、布局、组件、待还款，以及首页专用 `overview.css`。首页账户列表复用原有的账户编辑事件；没有新增 UI 依赖，没有改变业务规则、账本结构或存储方式。本机资源接口增加 PNG 支持以加载离线装饰。

已验证账户、账单、部分与全部还款、编辑与撤销、重复提交保护、保存失败回滚和备份功能。宽窗口与窄窗口预览使用隔离的示例账本，不使用个人数据。
