# zz记视觉设计规范

本次视觉升级采用浅色、编辑式排版和克制的组件层次。参考 [Hermes Agent 官网](https://hermes-agent.nousresearch.com/) 的标题优先级、清晰分区及品牌一致性，保留 zz记 的个人财务软件定位，不沿用参考网站的蓝色品牌、营销布局或插图。

## 现有问题与设计方向

旧样式多次叠加覆盖，9–11px 小字偏多，正文、金额、操作都倾向紫色。纹理、高光和多个渐变分散了关键信息。本次用单一 token 系统代替叠加主题，先确定待还款页的语言，再应用到总览、账户、统计和弹窗。

金额、还款状态和日期是优先信息。深灰紫只用于总额卡片、主操作与选中导航，正文和普通金额保持深色。白底卡片使用细边框，常规组件不依赖阴影。

## 色彩

| Token | 颜色 | 用途 |
| --- | --- | --- |
| `--bg` | `#F8F7FA` | 主内容背景 |
| `--surface` | `#FFFFFF` | 卡片、标题栏、导航 |
| `--surface-secondary` | `#F1EDF5` | 选中导航、弱强调 |
| `--purple` | `#8C75A8` | 图标、焦点、品牌强调 |
| `--purple-dark` | `#66517F` | 主操作与总额视觉锚点 |
| `--ink` | `#27232E` | 标题与关键金额 |
| `--text` | `#514B59` | 正文 |
| `--muted` | `#918A9A` | 次要元信息 |
| `--text-secondary` | `#756D7E` | 小字标签，保持可读性 |
| `--border` | `#E9E5ED` | 边框与分割线 |

逾期、已还清、今日到期使用独立的低饱和语义色，并同时显示文字，不只靠颜色表达状态。

## 排版

- 主标题：桌面 32px，窄窗口 28px，字重 600。
- 区域标题：17px，字重 600。
- 核心金额：32–36px，字重 600；明细金额 33px。
- 正文与主要操作：13px；标签、日期说明与辅助操作：11–12px。
- 中文字体按本机可用的 Noto Sans SC、思源黑体、微软雅黑等回退，无在线字体依赖。
- 数字采用 Segoe UI 等无衬线字体与 `tabular-nums`；品牌字标采用克制的衬线字形。

## 组件

- 标题栏高 44px，使用细分割线，保留全部原生控制与拖动。
- 导航宽 220px，窄窗口收至 196px 或 184px；导航项高 45px。
- 卡片圆角 12px，边框 1px；按钮和输入框圆角 8px。
- 采用 4、8、12、16、20、24、32、40px 间距刻度。
- 待还款总额使用深灰紫锚点，次级统计通过分割线组织。明细卡突出金额、状态、日期和操作。
- 明细在宽窗口为三列，普通桌面为两列，窄窗口为一列。内容独立滚动。
- Hover 仅改变边框、背景或文字，过渡 180ms；尊重减少动态效果的系统设置。
- Focus 使用品牌色细描边和柔和焦点环；错误与保存状态有明确文字反馈。
- 模态对话框使用普通半透明遮罩，不使用毛玻璃或滤镜。

## 文件组织与验证

`ui/style.css` 只引入四个模块：`tokens.css`、`layout.css`、`components.css`、`debts.css`。旧的 polish、refined、material 主题已移除，避免层叠覆盖。没有新增 UI 依赖，没有改变业务函数、账本结构或存储方式。

已验证账户、账单、部分与全部还款、编辑与撤销、重复提交保护、保存失败回滚和备份功能。宽窗口与窄窗口预览使用隔离的示例账本，不使用个人数据。
